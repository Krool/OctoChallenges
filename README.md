# OctoChallenges

by **Krool**

Shows your character's active leveling challenges (Hardcore, War Mode,
Slow & Steady, ...) on the paperdoll as an icon column with hover tooltips,
for the [OctoWoW](https://octowow.st) 1.12.1 private server.

- Icons appear left of your character model in the character frame (C).
- `/octochallenges` lists your active challenges in chat.

## Install

Paste this repository's URL into the OctoLauncher's **Install Addon** box,
or clone/copy this folder into `Interface/Addons/OctoChallenges`.

## Bonus: challenges on the character select screen

This addon also bridges your challenge data to the login screens. With the
companion client mod installed
([octowow-client-mods](https://github.com/Krool/octowow-client-mods)),
each character's challenges show directly on the character select list,
which also adds list reordering and pre-login sound settings.
